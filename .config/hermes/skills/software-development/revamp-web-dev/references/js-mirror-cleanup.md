# `.js` mirror cleanup (revamp-web-interface)

Transpiler mirrors: `*.js` files with a sibling `*.ts`/`*.tsx` of the same
basename, generated by a dev watcher. Real source is the `.ts`; the `.js` is
junk (often a stub like `export {};`, mtime newer than the `.ts`). Deleting
them is safe ONLY after the checks below. Verified on the 2026-08-23 session:
1321 untracked mirrors deleted, build/typecheck stayed green, 10 real
`apps/native` source `.js` files kept.

## Step 0 — confirm the pile is mirrors, not source

Spot-check 2-3 candidates: does `<name>.ts` exist next to `<name>.js`? If yes
and the `.js` is a transpile stub, you're looking at mirrors.

```bash
ls -la packages/ai/src/client.js packages/ai/src/client.ts   # .js newer, smaller = mirror
```

## Step 1 — classify every `.js` (mirror vs standalone source)

Run from repo root. `has_src` = sibling `.ts`/`.tsx` exists → mirror.

```bash
find . -name "*.js" -not -path "*/node_modules/*" -not -path "*/.git/*" \
  -not -path "*/dist/*" | grep -vE "/build/|/out/" > /tmp/all_js.txt
# mirrors = those with a .ts/.tsx sibling; standalone = without
```

Standalone (KEEP, real source) observed this repo:
`apps/native/config/version.js`, `apps/native/plugins/*.js`,
`apps/native/metro.config.js`, `apps/native/babel.config.js`,
`apps/native/eslint.config.js`, `apps/native/src/db/migrations/migrations.js`,
`doctor.config.js`, `scripts/*.js`.

## Step 2 — git tracking: use `git ls-files`, NOT `git status --porcelain`

PITFALL: `git status --porcelain -- <many paths>` silently returns EMPTY when
the arg list is large, which mislabels untracked mirrors as "tracked". This
caused a false "1322 tracked mirrors" reading on the first pass. Correct:

```bash
git ls-files '*.js' > /tmp/tracked_js.txt          # authoritative tracked set
git status --porcelain | grep '^??' > /tmp/untracked_all.txt   # untracked set
```

The deletion target = untracked `.js` that have a `.ts`/`.tsx` sibling
(mirrors), EXCLUDING tracked standalone source.

## Step 3 — explicit-import check (don't delete imported real source)

A `.js` imported by explicit path with no `.ts` sibling is real source.

```bash
grep -rnE "(from|import) ['\"][^'\"]+\.js['\"]" --include=*.ts --include=*.tsx \
  --include=*.mts . 2>/dev/null | grep -v node_modules | grep -v "/dist/"
```

If a hit's target has no `.ts` sibling, KEEP it. (Observed: `version.js` and two
native plugin `.js` are imported this way — all standalone source.)

## Step 4 — build the deletion list and delete

```python
# classify.py — writes /tmp/js-mirrors-to-delete.txt
import os, subprocess
root = "/Users/saileshbro/Projects/revamp-web-interface"
files = [l for l in open("/tmp/all_js.txt").read().splitlines() if l.strip()]
tracked = set(os.path.abspath(os.path.join(root, t))
              for t in subprocess.run(["git","ls-files","*.js"], cwd=root,
              capture_output=True, text=True).stdout.splitlines())
to_delete = []
for f in files:
    ab = os.path.abspath(f); base = f[:-3]
    has_src = os.path.exists(base+".ts") or os.path.exists(base+".tsx")
    if has_src and ab not in tracked:
        to_delete.append(f)
open("/tmp/js-mirrors-to-delete.txt","w").write("\n".join(to_delete))
print("delete:", len(to_delete))
```

```bash
xargs -I{} rm -f "{}" < /tmp/js-mirrors-to-delete.txt
# confirm only standalone source remains
find . -name "*.js" -not -path "*/node_modules/*" -not -path "*/.git/*" \
  -not -path "*/dist/*" | grep -vE "/build/|/out/" | wc -l   # expect ~10
```

(macOS `xargs` has no `-a`; use `xargs -I{} rm -f "{}" < file`.)

## Orphan-import check for generated components (separate task)

When untracked `apps/web/src/components/*` or `components/ui/*` appear (shadcn
fetch / sibling drop), verify they're imported before committing:

```bash
for c in app-sidebar data-table nav-main site-header alert-dialog button-group \
         item kbd message-scroller spinner switch; do
  n=$(grep -rln "components/$c" src --include=*.tsx --include=*.ts | \
      grep -v "components/$c.tsx" | wc -l)
  echo "$c imported by $n file(s)"
done
```

If 0 (or only imported by another orphan, e.g. untracked `components/app-sidebar.tsx`
while the live shell uses `@/components/observatory/app-sidebar`), the chain is
dead — leave it out of the commit and flag it to the user. Do NOT ship
unwired duplicate components.
